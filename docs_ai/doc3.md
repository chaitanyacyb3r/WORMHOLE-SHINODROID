### Next Steps After Asset Creation

1. **Import into Next.js:** Use `next/image` for all raster images with proper `width`, `height`, and `alt` attributes
2. **SVG logos:** Import as React components or use `next/image` with SVG
3. **Favicon:** Update `src/app/layout.tsx` metadata to reference new favicon files
4. **OG Image:** Add to metadata in `layout.tsx`:
    
    React
    
    ```
    export const metadata = {
      openGraph: {
        images: ['/og-image.png'],
      },
    }
    ```
