Java.enumerateMethods(query): enumerate methods matching query, specified as "class!method", with globs permitted. May also be suffixed with / and one or more modifiers:

```
Java.enumerateMethods(query)
```


```
query
```


```
"class!method"
```


```
/
```

- i: Case-insensitive matching.
- s: Include method signatures, so e.g. "putInt" becomes
"putInt(java.lang.String, int): void".
- u: User-defined classes only, ignoring system classes.

```
i
```


```
s
```


```

```


```

```


```
u
```

Java.perform(() => { const groups = Java.enumerateMethods('*youtube*!on*') console.log(JSON.stringify(groups, null, 2)); });
